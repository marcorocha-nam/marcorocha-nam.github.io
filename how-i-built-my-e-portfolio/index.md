
# How I Built My GitHub Pages E-Portfolio

## Introduction

This guide explains how I created my personal e-portfolio with GitHub Pages. 
It covers the initial repository setup, adding the theme, personalizing the portfolio, and publishing the site. 

## Milestone I: Creating the Portfolio

### 1. Create a GitHub Pages repository

I created a repository on GitHub named `marcorocha-nam.github.io`. The published website address is: [marcorocha-nam.github.io](https://marcorocha-nam.github.io/).

### 2. Clone the repository to my computer

I cloned the new repository to my computer using Visual Studio Code so I could edit its files locally. 
First, I opened the repository on GitHub, clicked Code, and copied its URL.In Visual Studio Code, I selected Git: Clone, pasted the URL, and chose the folder on my computer. Once cloning finished, I opened the repository in Visual Studio Code to begin editing.

### 3. Download the Minimal theme

### 4. Add the theme files to my repository

I unzipped the downloaded project and copied its contents into the local folder for `marcorocha-nam.github.io`

### 5. Configure the theme and portfolio details

I configured _config.yml to use jekyll-theme-minimal and set the site's title, description, headshot image, and download-button preference.

### 6. Write my portfolio homepage

I replaced the sample homepage content in the root index.md with my professional information. 

### 7. Commit & publish

After making the changes, I committed and pushed them to GitHub. 
I checked the repository's Actions tab for the Pages build and deployment, then visited [my published portfolio](https://marcorocha-nam.github.io/) to confirm the site was live.
